This folder contains the professor-facing reproducibility package for Project 2.

Archive:
- `project_2_competitive_news_spillovers_deliverable.zip`

What is included in the zip:
- project code needed for the pipeline;
- configuration and prompts;
- notebooks used for the analysis;
- raw, interim, and processed data;
- analysis outputs such as core tables, figures, and audit samples;
- a minimal `requirements.txt` and reproducibility `README.md`.

What is intentionally excluded:
- `.env` and any real API keys;
- the `.git` directory;
- report and presentation files;
- planning/help documentation not needed to rerun the project;
- logs, caches, and Python bytecode;
- report-specific output files prefixed with `report_`.
