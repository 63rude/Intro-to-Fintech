## What The Course Is About

This course is about how technology is reshaping financial services. It combines conceptual finance, real-world FinTech cases, data analysis, machine learning, blockchain, crypto, AI, and hands-on project work.

The stated course philosophy in Part 1 is to combine theory, real data, and hands-on analysis so students can evaluate FinTech companies critically, not just admire them.

## Main Themes

- FinTech disruption across payments, lending, wealth management, banking, insurance, and regulation.
- Blockchain, Bitcoin, crypto assets, smart contracts, DeFi, CBDCs, tokenization, and ICOs.
- Big data, machine learning, AI, NLP, LLM APIs, and AI agents in finance.
- Data-driven financial prediction and textual analysis.
- Business design for FinTech applications and disruption.
- Human-AI collaboration in readings, coding, analysis, and proposal writing.

## Practical Skill Emphasis

- Use Python and data tools for financial analysis.
- Build machine learning models for stock return prediction.
- Work with unstructured textual data using LLMs.
- Connect empirical findings to financial theory.
- Use AI tools, while documenting the human-AI interaction.
- Prepare written reports, code submissions, and business proposals.
